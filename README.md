## Private by design

- **Local-first** — your data stays in your browser; one-click backup to a file you own.
- **Optional end-to-end-encrypted sync** — the server only ever sees ciphertext; a recovery code, never an email reset.
- **No tracking, open source** — no analytics or cookies, a strict CSP, and a CI test that fails on any unapproved network call or storage.

## Get started

**Try it:** [the live demo](https://accretia.vercel.app/?demo) — a made-up household, nothing saved. **Keep it:** Data → *Use it as an app* installs it (Share → Add to Home Screen on iPhone). **Run it yourself:**

```bash
git clone https://github.com/tianyi-zhang-02/accretia.git && cd accretia && npm install && npm run dev
```
